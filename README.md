# dinghao0821 的个人主页

这是参考蓝白学术主页风格制作的个人主页，内容依据丁浩提供的中文简历整理。目前尚未发布。

已收录教育、科研、实习、项目及奖项，使用简历中的照片与学术邮箱。未包含电话号码或可下载的原始简历。TIP 论文发表状态未明确，因此暂列为研究工作；未添加未经确认的论文、代码链接。

## 修改资料

编辑 `profile.js` 中的姓名、简介和各栏目数组。文件开头有填写示例。头像位于 `assets/portrait.jpg`。页面支持手机浏览、深浅色切换、论文摘要展开。

## 发布到 GitHub Pages

1. 登录 https://github.com/dinghao0821 ，创建公开仓库 `dinghao0821.github.io`。若已有同名仓库，先检查原内容并备份，避免直接覆盖。
2. 把本文件夹内部的文件上传到仓库根目录，确保 `index.html` 直接在最外层，不要上传整个外层文件夹。
3. 提交后，打开仓库 Settings → Pages。
4. Source 选 Deploy from a branch；Branch 选 main；目录选 / (root)，保存。
5. 等待部署完成，访问 https://dinghao0821.github.io/ 。部署结果可在仓库 Actions 或 Pages 设置查看。

无需安装依赖，也无需执行构建。之后修改资料并提交，GitHub Pages 会重新发布。

参考：https://docs.github.com/en/pages/quickstart
